# 0% 保持高速的原因与风扇专用配置

2026-10-18。硬件 U16 V5F / VID:PID 2486:3217 / 固件 0.9.212.38 / 10 路。

## 结论和边界

`99` 中的 0 会被这版固件忽略，保留上一输出。0.1.3 对经过验证的这款硬件改用 `CC`，将目标通道暂时设置为固定模式 `S=1,V=0`；正百分比恢复外部模式，并每秒续发 `99`。没有将 0 改成 1，也没有发送全组停转或低于 25% 停转动作。

最终控制器实机第 2 路：80% 时 1498 RPM；切到 0%，第 4 秒 897、第 10 秒 890 RPM；1% 时约 884～889 RPM；再切 80%，末次 1487 RPM。**解决的是 0% 后仍维持先前高速；这把风扇在零目标下仍转，不能宣称逐路停转。** 未测电气占空比。

`F0` 固定零值曾经实测确认导致灯效重播，已排除。`CC` 绕过固件全局灯效配置路径，实机记录没有 F0。2026-10-18 追加反复切换测试期间现场确认 **灯效连续，没有重播**。这是肉眼观察；EE 配置回读本身不能证明播放位置连续。验证摘要见 [验证记录](../VALIDATION.zh-CN.md)。
